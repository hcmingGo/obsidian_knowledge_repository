# Obsidian 与 Claude Code 的分工模型

核心理念：Obsidian 负责"存储与呈现"，Claude Code 负责"整理与执行"。

- **Obsidian**：本地 Markdown 文件管理工具，核心优势是双向链接和关系图谱——笔记靠链接形成可生长的语义网络，而非简单的文件夹堆叠。数据本地存储，适合处理敏感信息，也便于用 Git／云盘做版本管理和备份。
- **Claude Code**：运行在终端里的 AI 编程与自动化代理，能读写本地文件系统、执行 shell 命令、理解自然语言指令。因为 Obsidian 知识库本质是一堆本地 Markdown 文件，Claude Code 可以把整个 Vault 当作工作目录来处理。

分工边界：用户负责输入原始信息、把关质量；AI 负责归档、打标签、建链接、生成周期性报告和成稿草稿。

**重要边界**：AI 也会犯错，可能做出看似合理实则牵强的关联，不能盲信；链接是 AI 建立的，但链接背后"为什么相关"需要用户自己理解和补充，否则知识网络只是好看，没有真正内化到用户的认知里。
