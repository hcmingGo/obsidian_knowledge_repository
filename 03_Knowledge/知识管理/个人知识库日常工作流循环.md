# 个人知识库日常工作流循环

一套跑起来之后的日常循环包含六个环节：

1. **随手收集**：读到的、想到的、开会记下的，不做任何分类判断，直接丢进 `00_Inbox`。
2. **AI 编译**：定期（如每天）触发 `/process-inbox`，AI 把碎片信息重写成原子化笔记，分类、打标签、建链接。
3. **知识结构化**：当某主题笔记积累到一定数量，触发 `/update-moc`，AI 生成或更新对应的主题地图（MOC），作为该领域的导航入口。
4. **检索与提问**：交互会话里直接问 Claude Code 关于知识库内容的问题，它可以搜索、读取相关笔记后给出有链接依据的回答。
5. **知识输出**：需要写文章、做汇报时，触发类似 `/draft-article "主题"` 的命令，让 AI 遍历相关笔记，产出初稿，用户在此基础上润色定稿。
6. **周期体检**：每周跑一次 `/weekly-review`，看孤立笔记、核心枢纽笔记、标签冗余情况，针对性补充和清理。
